# TAAZ Marketing Agent

Private, mobile-first personal marketing task and content manager for Azhar.

## Version 1
- Secure Supabase login
- Today dashboard
- Tasks and priorities
- Content schedule
- Four starter work areas: Dr Deepthi, ZUVEN Tech, Vishnu LinkedIn, Praveen LinkedIn
- Voice task capture in supported browsers
- Basic browser reminders while the PWA is active
- Installable Android PWA
- Daily brief that can be copied into ChatGPT

## Hosting
Designed for GitHub Pages under the `marketing-agent` repository.
